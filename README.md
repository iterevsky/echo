# ЭХО

«ЭХО» — иммерсивная веб-книга Ивана Итеревского-Кочетова. Психологический хоррор: новый двор, панельная девятиэтажка — и голос, который отвечает.

**Читать:** https://iterevsky.github.io/echo/

## Устройство

- Статический сайт: `index.html` + `style.css` + `script.js`, без сборщика и сторонних зависимостей; хостинг — GitHub Pages.
- Тексты глав лежат в `chapters.js` и никем не редактируются, кроме автора.
- Прогресс чтения и настройки читателя хранятся локально, в `localStorage` браузера (ключ `echo_state`) — никуда не отправляются.
- Проекторная заставка, CRT-эстетика, механические голоса и прочие эффекты — всё на CSS-анимациях и чистом JS.
- Офлайн: `sw.js` кэширует книгу целиком (app-shell, шрифты, кадры — по мере запроса). Перед любым обновлением файлов сайта (в том числе перед публикацией новой главы) увеличьте `CACHE_VERSION` в начале `sw.js` (`echo-v8` → `echo-v9`) — без этого читатели получат старый кэш.
- Шрифты (PT Serif, Golos Text) лежат локально в `fonts/` (лицензия OFL) — сайт не зависит от Google Fonts.
- Бейдж «новое»: даты выхода глав автор помечает в объекте `PUBLISHED_AT` в начале `chapters.js` (индекс главы → ISO-дата, напр. `68: '2026-03-01'`). Главы, вышедшие после прошлого визита читателя (12+ часов назад), получают циановую метку; после открытия глава метку теряет.
