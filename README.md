# ЭХО

«ЭХО» — иммерсивная веб-книга Ивана Итеревского-Кочетова.

**Читать:** https://iterevsky.github.io/echo/

## Устройство

- Статический сайт: `index.html` + `style.css` + `script.js`, без сборщика и сторонних зависимостей; хостинг — GitHub Pages.
- Тексты глав лежат в `chapters.js` и никем не редактируются, кроме автора.
- Прогресс чтения и настройки читателя хранятся локально, в `localStorage` браузера (ключ `echo_state`) — никуда не отправляются.
- Проекторная заставка, CRT-эстетика, механические голоса и прочие эффекты — всё на CSS-анимациях и чистом JS.
- Офлайн: `sw.js` кэширует книгу целиком (app-shell, шрифты, кадры — по мере запроса). Перед любым обновлением файлов сайта (в том числе перед публикацией новой главы) увеличьте `ECHO_VERSION` в `version.js` — Service Worker выводит имя кэша из этой единой версии (`echo-<ECHO_VERSION>`).

- Шрифты (PT Serif 1.000W OFL, Golos Text 2.004) лежат локально в `fonts/` — сайт не зависит от Google Fonts. Лицензия SIL OFL 1.1 и уведомления: [PT Serif](fonts/OFL-PT-Serif.txt), [Golos Text](fonts/OFL-Golos-Text.txt).
- Бейдж «новое» отключён и больше не используется. Даты выхода глав в `PUBLISHED_AT` сохранены в `chapters.js` как авторская инертная запись и не управляют интерфейсом.

## Публикация

`push-echo.cmd` проверяет чистое дерево и ветку, выполняет JS/статические проверки, поднимает `ECHO_VERSION`, публикует без force-push и сверяет версию и SHA-256 после деплоя. **Ограничение:** скрипт не может защитить или проверить загрузки, выполненные вручную через веб-интерфейс GitHub — такие изменения обходят все его проверки.
